Google Keep 읽기 전용 연결 테스트

개인 Gmail 계정에서 공식 Keep API에 접근할 수 있는지 실제로 확인합니다. 메모 생성·수정·삭제는 하지 않습니다.

  1. 같은 Google Cloud 프로젝트에서 Google Keep API를 활성화합니다.
  2. Google Auth Platform → 클라이언트에서 웹 애플리케이션의 승인된 JavaScript 원본에 을 추가합니다.
  3. 앱이 테스트 상태이면 대상 → 테스트 사용자에 본인 Gmail을 추가합니다.
클라이언트 보안 비밀이나 액세스 토큰은 입력하지 않습니다. 
설정을 읽는 중…

Keep 읽기 전용 권한만 요청하며, 조회 응답도 메모 이름 필드 최대 1개로 제한합니다. 결과에는 메모 ID·제목·본문·토큰을 넣지 않습니다.

로그인 창 안에서 오류가 나면 오류의 ‘세부정보’에서 오류 코드와 설명만 전달해주세요. 창 내부 오류는 이 페이지에 전달되지 않을 수 있습니다.
